# WeaponBot

NPC-бот "оружейник" для Paper/Spigot 1.20 на сервере **VortexiaPolit** — продаёт оружие и снаряжение, с автоматической ротацией страниц товаров.

## Команда

`/weaponbot <spawn|skin|page|rotate|info>` — право `weaponbot.admin` (по умолчанию только ОП).

## Зависимости

- **Vault** (обязательно)
- **ProtocolLib** (обязательно)
- **ItemsAdder** (опционально)

## Сборка

```
build.bat
```

## Совместимость

- Minecraft **1.20.1**
- Ядро сервера: **Mohist 1.20.1** (плагин используется на сервере VortexiaPolit)
- Написан на Bukkit/Spigot API, поэтому может работать и на Paper/Spigot 1.20.x
